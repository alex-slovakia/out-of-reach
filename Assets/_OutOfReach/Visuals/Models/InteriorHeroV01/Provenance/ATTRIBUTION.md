# INTERIOR-HERO-V01 provenance

Everything in `Assets/_OutOfReach/Visuals/Models/InteriorHeroV01/` is original work made for OUT OF REACH.

| Item | Source | Licence |
|---|---|---|
| Meshes `Models/InteriorHeroV01.fbx` | Generated by `Source~/build_interior_hero.py` (Blender 3.6) from `Source~/ih_cockpit.py`, `ih_habitat.py`, `ih_systems.py` on `Source~/ihkit.py` and the ship's own `Aurora7/Source/a7kit.py` | Project licence, original |
| Textures `Textures/IH_*.png`, atlas maps `ih_labels.json`, `ih_screens.json` | Generated by `Source~/ih_textures.py` (numpy + Pillow): procedural noise, drawn shapes and typeset labels | Project licence, original |
| Lettering on labels and displays | Rendered from `Assets/_OutOfReach/UI/Typography/BarlowCondensed-Bold.ttf` and `SourceSans3-*.otf`, already shipped with the project | SIL Open Font License 1.1 (see `UI/Typography/OFL.txt`, `BarlowCondensed-OFL.txt`); rendered text is not a font redistribution |
| Materials `Materials/IH_*.mat`, prefab `Prefabs/InteriorHeroV01.prefab` | Built by `Editor/InteriorHeroV01Builder.cs` from `Models/InteriorHeroV01_materials.json` | Project licence, original |

No third-party model, texture, photograph, scan or logo is used. No NASA insignia, agency logo or real programme
identifier appears on any label. The spacecraft, its part numbers (`AUR7-...`), unit names (`VEG-2`, `ARS-1`) and crew
names are fictional. The designs follow general public spaceflight practice (hook-and-loop patches, bungees, captive
fasteners, guarded switches, translation aids) and copy no specific vehicle, game or film asset.

Display pages are deliberately non-authoritative: schematics, plots and mode legends only. They show no simulated
resource value, mission day or distance; those stay with the game's own readouts.
