# Player-facing language: English

Explicit user decision, 14 November 2026: OUT OF REACH is an English-language game.

All player-facing menus, HUD, objectives, interaction prompts, instrument labels, chapter cards, accessibility captions, dialogue, voice recordings, credits and mission reports must be in English. Internal team discussion and handoffs may be in Slovak.

Spoken ship name and matching subtitle: "Aurora Seven". Graphic vessel marking: "AURORA-7". Use consistent English terminology: Mission Control, life support, stored oxygen (kg), cabin CO2 (ppm), battery energy (kWh), spare parts, airlock, awaiting reply, recovery planning.

Translate non-speech captions too: "[Hull impact. Alarm.]", "[Suit breathing.]". Preserve "PREVIOUSLY RECEIVED" on the briefing and "LOCAL BUFFER — OLD OUTBOUND RECORDING" on the false-signal replay. Do not accidentally ship Slovak working notes in these captions.

This owner-local record is an integration handoff. The designated integrator should propagate the user decision into shared PRODUCT/TASKS documentation when coordinating the next shared-file change. No shared file was changed from this feature branch.
