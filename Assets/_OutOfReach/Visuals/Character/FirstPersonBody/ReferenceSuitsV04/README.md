# ReferenceSuitsV04 (SUITS-V04, work in progress)

Alternative WORK/EVA character attempt for the 18:30 CET suit decision (#7). Built from MakeHuman CC0 assets
(base mesh, default skeleton and weights, male targets, casualsuit02/shoes02/short02/high-poly eyes) on the
UNCHANGED FitV02 rig: the FitV02 164-bone bind equals MakeHuman's default skeleton on the neutral base mesh
(max joint difference 2e-7 m), so the original MakeHuman weights skin the new mesh directly. Arms and hands keep the
exact base geometry (hand joint error 0.0 m) so the game's grip calibration stays valid.

Proof 1 (renders only): `Previews~/proof1_front_back.png`, `Previews~/proof1_lookdown.png`. FBX, materials and checks follow.
