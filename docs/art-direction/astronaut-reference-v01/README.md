# AURORA-7 astronaut reference

These user-approved front and back concept boards guide future modeling of the fictional AURORA-7 crew member. Use original fictional markings for any mission patches.

## Cabin clothing

![AURORA-7 crew member in cabin clothing, front and back](cabin-front-back.png)

Navy long-sleeve shirt, charcoal cargo trousers, low-profile work shoes and bare hands.

## EVA suit

![AURORA-7 crew member in EVA suit, front and back](eva-front-back.png)

Off-white layered suit, gold visor, helmet lights, chest controls, articulated gloves and a rear life-support pack. Use the official references to check suit components and proportions.
